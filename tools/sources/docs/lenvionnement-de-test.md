# L'environnement de test

Pour vous permettre de tester vos développements, un environnement de test mySilae Paie et un compte API de test sont mis à votre disposition.

L'environnement de test est un domaine Silae sur une plateforme de test. À la création de votre environnement de test, vous recevrez par mail les éléments permettant de vous connecter à ce domaine (url d'accès personnalisée et compte Silae).

Pour pouvoir tester correctement, vous aurez besoin :

- D'au moins un dossier Silae
- De créer une configuration d'accès API sur ce(s) dossier(s)
- D'avoir activé votre compte API de test dans le portail API

Si vous êtes un éditeur, nous vous encourageons à vous rapprocher du Partenaire Silae avec qui vous êtes en contact, pour qu'il vous fournisse un dossier de paie : par exemple une copie du dossier de paie de votre client commun.

Pour importer le dossier, il suffit de se rendre dans l'onglet **Outils**, de cliquer sur le bouton **Import d'un dossier de paie** puis de renseigner le chemin d'accès au fichier du dossier de paie (*Bouton Parcourir*). Après avoir confirmé en saisissant **OUI**, le dossier de paie sera visible à votre prochaine connexion. Si vous importez plusieurs dossiers de paie, un onglet **Production** fera son apparition, listant les dossiers importés.
