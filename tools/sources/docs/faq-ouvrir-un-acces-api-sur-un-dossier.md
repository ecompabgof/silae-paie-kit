# FAQ - Ouvrir un accès API sur un dossier

## Introduction

Cet article permet de connaître les démarches à suivre pour l'ouverture d'un accès API sur un ou plusieurs dossiers de paie selon votre profil et votre besoin.

***Hormis pendant la phase de contractualisation et de la mise en place des comptes API, Silae n'intervient en aucun cas dans le processus d'ouverture d'accès API sur un/des dossier(s) de paie. En tant que partenaire Silae, vous êtes totalement autonome.***

## Vous êtes partenaire Silae (Expert Comptable, revendeur…)

La demande concerne :

### Un usage interne

Vous souhaitez exploiter les APIs en interne pour automatiser certaines tâches et ainsi optimiser la productivité de votre cabinet.

Il vous faut remplir le formulaire de demande de création de compte API en spécifiant le modèle qui correspond à votre besoin : **Partenaire - Usage interne Paie (Modèle 1A**) et/ou **Partenaire - Usage interne RH (Modèle 1B**). Pour plus de détails, rapprochez vous de votre contact commercial Silae.

Une fois la demande traitée, un ou plusieurs comptes API seront alors disponibles selon votre demande.

Pour la mise en route, un [guide de démarrage](https://silae-api.document360.io/docs/guide-de-demarrage) est à votre disposition.

### Une mise à disposition à l'un de vos clients

Un de vos clients souhaite bénéficier d'un accès API pour pouvoir interconnecter mySilae Paie à ses outils internes ou à une ou plusieurs solutions éditeurs.

La demande concerne :

#### Une connexion à une solution éditeur partenaire API Silae

Si l'éditeur fait partie de cette liste : [Quels sont les éditeurs qui sont partenaires API Silae ?](https://silae-api.document360.io/docs/faq-1#quels-sont-les-%C3%A9diteurs-qui-sont-partenaires-api-silae), vous devez configurer un accès API pour le compte API de l'éditeur en question. La création d'une configuration d'accès API est décrite dans la fiche [Comment donner les accès API à un éditeur partenaire API Silae ?](https://silae-api.document360.io/docs/faq-1#comment-donner-les-acc%C3%A8s-api-%C3%A0-un-%C3%A9diteur-partenaire-api-silaei).

Une fois la configuration d'accès créée, vous devez prévenir votre client qui en informe à son tour son éditeur.

Cette même configuration API apparaîtra automatiquement dans la liste des configurations d'accès API au niveau du Portail API de l'éditeur (cf. détail dans la section [Portail API](https://silae-api.document360.io/docs/presentation-du-portail-api)). L'éditeur sera alors en mesure d'activer la configuration d'accès API depuis son portail et de générer la clé qui lui sera nécessaire lors du processus d'authentification/autorisation.

#### Une connexion à des outils internes ou à des solutions dont les éditeurs ne sont pas partenaire API Silae

Dans ce cas, il est nécessaire de remplir le formulaire de demande de création de compte API en spécifiant le modèle qui correspond à votre besoin : **Partenaire-Client Final - Mise à disposition compte API (Modèle 2)**. Pour plus de détails, rapprochez vous de votre contact commercial Silae.

Une fois la demande traitée, un compte API sera alors disponible. Pour la mise en route, un [guide de démarrage](https://silae-api.document360.io/docs/guide-de-demarrage) est à votre disposition.

Les identifiants API ainsi obtenus sont à transmettre à votre client qui les communique à son tour à son éditeur, i nécessaire, pour lui permettre de se connecter via API.

## Vous êtes éditeur de logiciels

### Logiciel de comptabilité

Vous êtes éditeur de logiciel de comptabilité et vous souhaitez devenir partenaire API Silae afin que vos clients puissent interconnecter votre solution à mySilae Paie. Il est nécessaire de nous contacter par [mail] afin de souscrire au contrat **Éditeur - Écritures comptables (Modèle 4)**.

### Autres logiciels

Votre client, équipé de votre solution, souhaite l'interconnecter avec mySilae Paie. Pour obtenir un accès API il faut que votre client se rapproche de son partenaire Silae qui gère son dossier de paie (Expert comptable, revendeur…), afin qu'il puisse réaliser les démarches nécessaires.

## Vous êtes client final d'un partenaire Silae

Vous êtes un client final d'un partenaire Silae et vous souhaitez utiliser les API pour pouvoir interconnecter vos solutions internes ou autres à mySilae Paie. Pour obtenir un accès API il faut vous rapprocher de votre partenaire Silae qui gère votre dossier (Expert comptable, revendeur…), pour qu'il réalise les démarches nécessaires.

## Vous n'êtes pas partenaire Silae

Vous souhaitez devenir Partenaire Silae, vous n'avez pas de contact commercial Silae, vous pouvez nous contacter en utilisant le [formulaire de contact sur notre site internet](https://www2.silae.fr/contact).
