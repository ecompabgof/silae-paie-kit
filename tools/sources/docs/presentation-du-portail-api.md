# Présentation du portail API

Le portail API permet de gérer sa société, ses comptes API et les configurations d'accès API.

## Création des accès

Création de vos accès

**Si vous êtes un éditeur**, la création de votre société, des comptes API et de l'utilisateur principal de votre société dans le portail API se fait suite à la signature du contrat API REST, si vous avez fourni toutes les informations nécessaires (cf. Article [Contractualisation et facturation](https://silae-api.document360.io/docs/contractualisation-et-facturation#contractualisation)).

**Si vous êtes un partenaire**, vous devez faire une demande à votre contact commercial, avec les informations nécessaires (cf. Article [Contractualisation et facturation](https://silae-api.document360.io/docs/contractualisation-et-facturation#contractualisation)) pour lancer la création de votre société, des comptes API et de l'utilisateur principal de votre société dans le portail API. En prérequis il faudra avoir signé le contrat de distribution avec l'annexe 7 - API ou avoir signé l'avenant correspondant.

À la création de la société dans le portail API par les équipes Silae, un mail de confirmation est envoyé à l'adresse mail renseignée pour désigner le compte principal du portail. La personne doit ensuite renseigner son nom, prénom et mot de passe pour finaliser la création de son compte utilisateur sur portail API.

## Page d'accueil

![Portail_API-Accueil](https://cdn.document360.io/1e4e518a-c4e9-489d-bc9a-7ae743d5395f/Images/Documentation/Portail_API-Accueil.png?sv=2026-02-06&spr=https&st=2026-11-13T19%3A15%3A02Z&se=2026-11-13T20%3A15%3A02Z&sr=c&sp=r&sig=f7q5axaMbcY4pfgVjHYaZ3OzOsuwd3deNN87G71Zhqo%3D)

La page d'accueil du portail API accessible depuis l'URL de connexion : [https://api-portal.silae.fr](https://api-portal.silae.fr) propose d'accéder à :

- la liste des comptes API
- la gestion de la fiche société (si l'utilisateur possède les droits).
- la documentation API mySilae Paie

### Mes comptes API

Ce menu permet à l'utilisateur de voir la liste des comptes API auquel il a accès. La gestion des comptes API est décrite dans la [gestion des comptes API](https://silae-api.document360.io/docs/gestion-des-comptes-api).

### Ma société

Ce menu n'est accessible que si on a accordé à l'utilisateur les droits d'accès à la gestion de la société. Il permet à l'utilisateur d'accéder à la [gestion de la société](https://silae-api.document360.io/api-rest/docs/gestion-de-la-societe).

### Documentation API mySilae Paie

Ce menu permet d'accéder à la documentation que vous consultez actuellement.
